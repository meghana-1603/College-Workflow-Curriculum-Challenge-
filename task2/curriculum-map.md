## Audit interpretation

The curriculum provides a broad foundation in programming, mathematics, computing systems, databases, machine learning and artificial intelligence. The proposed redesign therefore prioritizes improving practical assessment in existing courses before recommending additional credit-bearing courses.

The main areas for proposed improvement are:

- Software testing, debugging and API reliability.
- Data quality, transformation and end-to-end data pipelines.
- Cloud deployment, monitoring and operational practices.
- Responsible AI, model evaluation and error analysis.
- Reproducible projects with documented testing and verification.

Proposed updates should be compared with existing learning outcomes and assessments to avoid duplicating material already adequately covered. Any additions or changes to credit requirements would remain subject to institutional approval and applicable programme regulations.
